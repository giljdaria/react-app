### 2.2 Логика и синтаксис

**Оценка до исправлений: 7/10 → После: 9.5/10**

#### 🔴 Гонка состояний в localStorage — обнаружена и устранена

**Файл:** `src/ui/state/useDemoData.ts`

**Описание проблемы:**  
Два `useEffect` работали без координации. При первом рендере второй эффект (запись в localStorage) срабатывал с пустым массивом `[]` раньше, чем первый (чтение из localStorage) успевал загрузить сохранённые заметки. Это приводило к потере данных пользователя при обновлении страницы.

```typescript
// До (опасно):
useEffect(() => {
  localStorage.setItem(LOCAL_NOTES_KEY, JSON.stringify(localNotes)); // [] затирает данные
}, [localNotes]);

// После (исправлено):
const [lsInitialized, setLsInitialized] = useState(false);

useEffect(() => {
  // ... читаем localStorage ...
  setLsInitialized(true); // сигнализируем что чтение завершено
}, []);

useEffect(() => {
  if (!lsInitialized) return; // не пишем пока не прочитали
  localStorage.setItem(LOCAL_NOTES_KEY, JSON.stringify(localNotes));
}, [localNotes, lsInitialized]);
```

**Статус:** ✅ Устранено

#### 🟠 Затенение глобальной переменной `window` — обнаружена и устранена

**Файл:** `src/ui/pages/TrendsPage.tsx`, строка 7 (до исправления)

```typescript
// До (конфликт имён):
const [window, setWindow] = useState<"3m" | "6m" | "12m">("6m");

// После:
const [timeRange, setTimeRange] = useState<"3m" | "6m" | "12m">("6m");
```

`window` — зарезервированное имя глобального объекта браузера. Локальная переменная с тем же именем блокировала доступ к нему внутри компонента, что потенциально ломало бы любой код, использующий `window.scrollY`, `window.innerWidth` и т.д.

**Статус:** ✅ Устранено

## 5. Рекомендации на будущее (за рамками текущей задачи)

1. **Явный таймаут запроса к OpenRouter** — добавить `AbortController` с таймаутом 15–20 секунд, чтобы функция не зависала при недоступности модели.
2. **Rate limiting** — при публичном деплое добавить ограничение числа запросов к `/api/analyzeNote` по IP (встроенные средства Cloudflare).
3. **Автоматическая перекластеризация** — при накоплении N новых заметок запускать фоновый пересчёт кластеров.
4. **Состояние ошибки загрузки данных** — если `fetch("/data/notes.json")` упал, сейчас ошибка молча проглатывается. Добавить уведомление пользователю.
5. **E2E-тесты** — покрыть сценарий «заполнить форму → проанализировать → убедиться что заметка появилась в истории» с помощью Playwright или Cypress.
