# AI-анализатор обратной связи (demo)

Сервис превращает заметки медпредставителей после визитов к врачам в **темы**, **сентимент по темам**, **кластеры**, **тренды** и **actionable-инсайты** с конкретными рекомендациями и цитатами-доказательствами.

Демо-данные синтетические: 30 заметок, 18 врачей, 5 препаратов, 8 кластеров, охват июнь 2025 — май 2026 (12 месяцев).

---

## Функциональность

| Экран | Что делает |
|---|---|
| **Обзор** | График сентимента по времени (12 мес.), топ-5 возражений, топ-3 преимущества, раздел «Рекомендации» с actionable-инсайтами |
| **Импорт** | Ручной ввод заметки с привязкой к врачу / препарату / дате, AI-анализ в реальном времени, список добавленных заметок |
| **Кластеры** | 8 смысловых групп с тональностью, цитатами и признаком «растущий кластер», фильтр по теме |
| **Тренды** | Динамика негативного сентимента по 3 темам за 3 / 6 / 12 месяцев + список растущих кластеров с % роста |

### Стек

- **React 18 + TypeScript + Vite** — SPA, горячая перезагрузка, типобезопасность
- **React Router v6** — клиентская навигация между экранами
- **Recharts** — декларативные графики (AreaChart, LineChart) с вертикальными подписями оси X
- **Zod** — валидация схем данных: защита от некорректного ответа AI на клиенте и сервере
- **Cloudflare Pages + Functions** — хостинг + serverless-прокси к OpenRouter; секреты хранятся в переменных среды Cloudflare и **никогда не попадают в браузер**
- **OpenRouter** — единая точка доступа к LLM (позволяет менять модель через переменную среды без изменения кода)
- **localStorage** — временное хранение заметок, добавленных вручную (с защитой от гонки состояний при инициализации)

## Как работает AI-интеграция

```
Браузер → POST /api/analyzeNote (ваш домен)
              ↓
        Cloudflare Function
          - добавляет OPENROUTER_API_KEY из secrets
          - формирует промпт с system + user
          ↓
        OpenRouter API → LLM
          - возвращает JSON: { noteId, topics: [{ topic, sentiment, rationale }] }
          ↓
        Cloudflare Function
          - извлекает первый JSON-объект из ответа (защита от markdown-обёртки)
          - валидирует по Zod-схеме
          ↓
Браузер → отображает карточки по темам с тональностью и пояснением (rationale)
```

Ключ API хранится **только на сервере** (Cloudflare secrets). Пользователь его никогда не видит.

### Используемые модели

По умолчанию (разработка): `meta-llama/llama-3.2-3b-instruct:free` — бесплатная модель через OpenRouter.

Для продакшна рекомендуется `claude-sonnet-4-6` или `claude-sonnet-4-5` от Anthropic — точнее в structured output и лучше понимает медицинский контекст. Модель меняется через переменную среды `OPENROUTER_MODEL` без изменения кода.

**Актуальная линейка Anthropic:**

| Модель | Строка модели | Применение |
|---|---|---|
| Claude Haiku 4.5 | `claude-haiku-4-5-20251001` | Быстро и дёшево — массовая классификация, большой объём |
| Claude Sonnet 4.5 | `claude-sonnet-4-5` | Баланс качества и цены — основные продакшн-задачи |
| Claude Sonnet 4.6 | `claude-sonnet-4-6` | Текущий флагман среднего сегмента — лучшее следование инструкциям |
| Claude Opus 4.6 | `claude-opus-4-6` | Сложный многошаговый анализ — когда важнее качество, чем скорость |

## Принятые архитектурные решения

### Почему промпт на русском, а темы на английском
Промпт к LLM написан на русском — это язык заметок. Названия тем (`efficacy`, `safety` и т.д.) остаются английскими внутри кода и JSON, но переводятся на русский при отображении через словари в компонентах. Это позволяет LLM-модели стабильно следовать схеме (английские enum-значения она знает лучше) и одновременно показывать интерфейс на русском.

### Почему кластеры статичны, а не считаются в реальном времени
Настоящая кластеризация (embeddings + k-means) требует батчевой обработки всех заметок — это нецелесообразно при каждом запросе. В продакшн-архитектуре это фоновая задача: запускается раз в сутки или при накоплении N новых заметок. В демо кластеры статичны и репрезентативны.

### Почему localStorage, а не база данных
Демо-проект не требует серверного хранилища. localStorage достаточно для демонстрации сценария «добавил заметку — она видна на других экранах». При новом деплое JSON-файлы обновляются до исходного набора, а данные браузера сохраняются независимо.

### Защита от гонки состояний в localStorage
Два `useEffect` в `useDemoData.ts` координируются через флаг `lsInitialized`: запись в localStorage происходит только после того, как чтение завершено. Это предотвращает затирание сохранённых заметок пустым массивом при первом рендере.

### Вертикальные подписи на оси X
При 12 точках данных горизонтальные подписи накладываются друг на друга. Использован параметр `angle: -90` в `tick` компонента `XAxis` (Recharts) с увеличенной высотой оси (`height={56}`).

## Переменные среды (Cloudflare secrets)

| Переменная | Обязательно | Описание |
|---|---|---|
| `OPENROUTER_API_KEY` | ✅ | Ключ доступа к OpenRouter |
| `OPENROUTER_MODEL` | нет | Модель (default: `meta-llama/llama-3.2-3b-instruct:free`) |
| `OPENROUTER_SITE_URL` | нет | Заголовок для OpenRouter (ваш URL) |
| `OPENROUTER_APP_NAME` | нет | Заголовок для OpenRouter (название приложения) |

## Запуск локально

Требования: Node.js 18+.

```bash
npm install
npm run dev
```

Откройте URL, который покажет Vite (обычно `http://localhost:5173`).

> При локальном запуске функция `/api/analyzeNote` недоступна без Wrangler. Демо-данные загружаются из `public/data/` и работают полностью офлайн.

## Сборка и деплой

### Локальная сборка

```bash
npm run build
# артефакты в папке dist/
```

### ZIP-архив (Windows / PowerShell)

```powershell
.\tools\make-zip.ps1
# создаёт ai-feedback-analyzer.zip без node_modules, dist, .git
```

### Деплой на Cloudflare Pages

1. Подключить репозиторий в Cloudflare Pages
2. Настройки сборки:
   - Build command: `npm run build`
   - Output directory: `dist`
3. Включить Pages Functions (папка `functions/` подхватывается автоматически)
4. Добавить secrets (см. таблицу выше)

## Демо-данные

Все данные синтетические. Сбрасываются при каждом деплое до исходного набора:

- **18 врачей** — реальные специальности (кардиолог, терапевт, невролог, эндокринолог, гастроэнтеролог) и города РФ
- **5 препаратов** — выдуманные торговые названия (КардиоФлекс, НейроВита, ГастроГард, ГлюкоБаланс, РиноСейф)
- **30 заметок** — имитируют реальные записи медпредставителей, охват октябрь 2025 — май 2026
- **8 кластеров** — смысловые группы с тональностью и цитатами
- **3 инсайта** — с наблюдениями, действиями и доказательствами
- **Агрегаты** — статистика за **12 месяцев** (июнь 2025 — май 2026) для графиков и топов

Заметки, добавленные через экран «Импорт», хранятся в `localStorage` браузера и видны на всех экранах до очистки браузера или нового деплоя.
